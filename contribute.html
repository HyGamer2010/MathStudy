How to Contribute

If you are interested in contributing to the website and helping add content you would find useful, there are 2 main ways to go about doing so.
1. Tell me what to add
This one is pretty simple. Simply send me an email containing 4 pieces of information:
1. The subject
2. The unit
3. The topic
4. What kinds of problems fall under the category

This will allow me to input info in the format I already use for the website as seen on the main page. 
For example:

1. Advanced Math
2. Unit 6
3. Law of Sines and Cosines
4. Types of problems:
- Side/angle pair with extra side law of sines
- Side/angle pair with extra angle law of sines
- Ambiguous case problems
- Side angle side law of cosines
- Side side side law of cosines

With this info, I would be able to create the problems found on the website
2. Send me a json file with problems already made in it
If you want more control over what goes onto the website, you can create a json file with the problem formats already created in it.

The format for creating the json files follows this format: 


{
    "Types": [
        {
            "Problem": [
                //Problem lines
            ],
            "Answer": [
                //Answer lines
            ],
            "Explanation": [
                //Explanation lines
            ]
        },
        {
            //Repeat for every problem type
        }
    ]
}



To see this format in action, let's take a look at a problem type found in Linearization.json


{
    "Types"  [
        {
            "Problem": [
                "`f(x) = %eq%`",
                "`a = %a%`<br>",
                "a) Find `L(x)` of `f(x)`",
                "b) Find `L(%x%)`"
            ],
            "Answer":[
                "a) `L(x) = %f(a)% + %f'(a)%(x-%a%)`",
                "b) `%ans%`"
            ],
            "Explanation":[
                "<span class='sep'>a)</span>",
                "`f(x) = %eq%`",
                "`f'(x) = %deriv%`",
                "We use these to find at a",
                "`f(%a%) = %eqa%`",
                "`f(%a%) = %f(a)%`",
                "`f'(%a%) = %deriva%`",
                "`f'(%a%) = %f'(a)%`",
                "Plug into `L(x) = f(a) + f'(a)(x-a)`",
                "`L(x) = f(%a%) + f'(%a%)(x-%a%)`",
                "`L(x) = %f(a)% + %f'(a)%(x-%a%)`",
                "<span class='sep'>b)</span>",
                "Plug into `L(x) = %f(a)% + %f'(a)%(x-%a%)`",
                "`L(%x%) = %f(a)% + %f'(a)%(%x%-%a%)`",
                "`L(%x%) = %ans%`"
            ]
        }
    ]
}



As you can see in this problem type, Problem is split into 4 strings, thus meaning there are 4 lines. Same applies to the Answer and explanation parts.

Everywhere where you see % signs surrounding a word/letter, that is a variable that will be randomly generated when the problem. For example, %eq% is the randomly generated equation and %deriv% is the derivative of the equation.

For any of these, just explain what each variable means and which ones should be generated randomly as well as their range. For example, if you had a side length of a triangle, the desired range could be [2, 10] to make sure the numbers aren't too large.

For stuff like <span class='sep'>b)</span>, these are separators created by using an HTML tag. When creating the json files, you don't have to worry about typing out the proper HTML tags for things like separators, special fonts, or pictures. Just signify what they are and I will fix it when implementing it since I will be reviewing all json files before uploading them anyway.

Finally, make sure you surround anything that has to do with the math behind it with graves(`). That is what tells the website what to render as math equations.

If there is more nuance to it, I would probably prefer you just tell me what I should do rather than trying to create a json file in all honesty.

Once you create the json file, you can then send it to me via email.
